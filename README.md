# Домашняя работа · Вариант 5

Транслятор учебного конфигурационного языка в XML. Синтаксический
анализатор Lark строит дерево по грамматике `src/config.lark`.

## Установка и проверка

Требуется Python 3.10 или новее. Из корня репозитория:

```sh
python3 -m venv .venv
. .venv/bin/activate
python -m pip install -r requirements.txt
make build
make test
```

Переменная `PYTHON` в Makefile задаёт интерпретатор (по умолчанию python3).

## Язык и формат результата

- Однострочный комментарий начинается с заглавной `C` и длится до
  конца строки. Блок между `{-` и `-}` может занимать несколько строк.
- Литерал числа содержит цифры и обязательную точку, например `12.`
  или `0.25`. Внутри выражений также допустимы целые операнды,
  как в примере из задания `$+ имя 1$` (имя в программе пишется латиницей).
- `(list 1. (list 2. 3.))` задаёт массив. Порядок и вложенность
  переносятся в XML. Пустой массив записывается как `(list)`.
- `var имя значение;` объявляет константу. Имена состоят из строчных
  латинских букв. Ссылка в выражении обращается к предыдущему объявлению.
- `$+ a 1$`, `$- a 1$` и `$pow a 2$` выполняют сложение, вычитание
  и возведение в степень. Оба операнда должны быть числами. Выражения
  можно вкладывать и использовать внутри массивов. Для арифметики
  используется Decimal со стандартной точностью 28 значащих цифр.

CLI читает stdin до конца и печатает один документ с корнем `config`.
Объявления становятся элементами `var` с атрибутом `name`,
числа и массивы — элементами `number` и `list`. Самостоятельные
значения попадают непосредственно в корень в исходном порядке.
При ошибке CLI завершает работу с кодом 1 и пишет сообщение в stderr.
Синтаксическая ошибка сопровождается номером строки и столбца.

```sh
echo 'var x 2.; $pow x 3$' | python -m src.cli
```

```xml
<config>
  <var name="x">
    <number>2</number>
  </var>
  <number>8</number>
</config>
```
